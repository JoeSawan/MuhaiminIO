# شرح أوامر التحكم في متحكم ATmega328 عبر السيريال

## جدول الأوامر المدعومة

| رقم الأمر | الوصف                    | المعطيات المطلوبة                          | مثال استخدام     | الاستجابة/الخطأ                     |
| --------- | ------------------------ | ------------------------------------------ | ---------------- | ----------------------------------- |
| 1         | قراءة إشارة أنالوج       | `<pin>` (0-7)                              | `1 0`            | `1 0 [قيمة 0-1023]`                 |
| 2         | قراءة منفذ كامل          | `<port>` (2: PORTB, 3: PORTC, 4: PORTD)    | `2 3`            | `2 3 [قيمة 0-255]`                  |
| 3         | كتابة قيمة لمنفذ         | `<port>` (2 أو 4), `<value>` (0-255)       | `3 2 255`        | `OK 3` أو `ERROR 3`                 |
| 4         | كتابة قيمة لمنفذ (WDDRx) | `<port>` (2-4), `<value>` (0-255)          | `4 3 0b11110000` | `OK 4` أو `ERROR 4`                 |
| 5         | قراءة دبوس رقمي          | `<pin>` (0-21)                             | `5 13`           | قيمة الدبوس (HIGH/LOW) أو `ERROR 5` |
| 6         | كتابة دبوس رقمي          | `<pin>` (0-13), `<state>` (0/1)            | `6 9 1`          | `OK 6` أو `ERROR 6`                 |
| 7         | إخراج إشارة PWM          | `<pin>` (3,5,6,9,10,11), `<value>` (0-255) | `7 11 128`       | `OK 7` أو `ERROR 7`                 |
