# شرح أوامر التحكم في متحكم ATmega328 عبر السيريال

## جدول الأوامر المدعومة

| رقم الأمر | الوصف                     | المعطيات المطلوبة                          | مثال استخدام      | الاستجابة/الخطأ                                |
|-----------|---------------------------|---------------------------------------------|--------------------|-----------------------------------------------|
| 1         | قراءة إشارة أنالوج        | `<pin>` (0-7 أو 9 لجميع الدبابيس)          | `1 9`              | `1 [pin] [قيمة 0-1023]` لكل دبوس عند استخدام 9 |
| 2         | قراءة منفذ كامل           | `<port>` (2: PORTB، 3: PORTC، 4: PORTD أو 5 لجميع المنافذ) | `2 5`              | `5 [port] [قيمة 0-255]` لكل منفذ عند استخدام 5 |
| 3         | كتابة قيمة لمنفذ          | `<port>` (2-4)، `<value>` (0-255)           | `3 2 127`          | `OK 3` أو `ERROR 3: Invalid port/value`        |
| 4         | ضبط اتجاه المنفذ (DDRx)   | `<port>` (2-4)، `<value>` (0-255)           | `4 3 0b111111`     | `OK 4` أو `ERROR 4: Invalid port/value`        |
| 5         | قراءة دبوس رقمي           | `<pin>` (0-21 يشمل A0-A7)                  | `5 15`             | `HIGH`/`LOW` أو `ERROR 5: Invalid pin`         |
| 6         | كتابة دبوس رقمي           | `<pin>` (0-19)، `<state>` (0/1)             | `6 18 1`           | `OK 6` أو `ERROR 6: Invalid pin/state`         |
| 7         | إخراج إشارة PWM           | `<pin>` (3,5,6,9,10,11)، `<value>` (0-255)  | `7 9 200`          | `OK 7` أو `ERROR 7: Invalid pin/value`         |
| 8         | ضبط اتجاه الدبوس          | `<pin>` (0-19)، `<mode>` (0: INPUT، 1: OUTPUT)| `8 7 1`          | `OK 8` أو `ERROR 8: Invalid pin/mode`          |

## ملاحظات هامة:
### الأمر 1:
- عند استخدام `9` كمعطى: يقرأ جميع الدبابيس التناظرية (A0-A7) بالتسلسل.
- مثال استجابة عند `1 9`:  
-1 0 512
-1 1 1023
-...
-1 7 0

### الأمر 2:
- المنافذ المقبولة:
- `2`: PORTB (الدبابيس الرقمية 8-13)
- `3`: PORTC (الدبابيس التناظرية A0-A5)
- `4`: PORTD (الدبابيس الرقمية 0-7)
- `5`: قراءة جميع المنافذ (B, C, D)

### الأمر 3 و4:
- قيود الكتابة على المنافذ:
- **PORTB (2)**: البتات 0-5 فقط (القيمة تُقنَّع بـ `0b00111111`).
- **PORTC (3)**: البتات 0-5 فقط (القيمة تُقنَّع بـ `0b00111111`).
- **PORTD (4)**: البتات 2-7 فقط (القيمة تُقنَّع بـ `0b11111100`).

### الأمر 5:
- الدبابيس 0-13: دبابيس رقمية قياسية.
- الدبابيس 14-21: الدبابيس التناظرية A0-A7 (تُعامل كدبابيس رقمية 14-21).

### الأمر 6:
- يدعم الدبابيس الرقمية 0-19 (يشمل A0-A5 كدبابيس رقمية 14-19).

### الأمر 8:
- `0`: يُعيّن الدبوس كـ INPUT.
- `1`: يُعيّن الدبوس كـ OUTPUT.

---

## أمثلة أخطاء شائعة:
- `ERROR 1: Invalid analog pin`: عند استخدام قيم خارج 0-7 أو 9.
- `ERROR 3: Invalid port(2-4)`: عند محاولة الكتابة على PORT غير موجود.
- `ERROR 7: Invalid PWM pin`: عند استخدام دبوس غير مدعوم لـ PWM مثل pin 4.
